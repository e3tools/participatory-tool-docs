=======================
Assign Form permissions
=======================

This feature enables assignment of permissions to :doc:`engagement profiles <engagement-profile>`.

.. image:: ../_static/images/engagement-profile-user-assignment-new.png
    :align: center
    :alt: Engagement profile user assignment


- A user is assigned to a specific :doc:`engagement profiles <engagement-profile>`. Each profile is a grouping of multiple engagement form groups
- Assigning permissions this way eases user management as when a user moves to a different department, you just assign them to the new profile
